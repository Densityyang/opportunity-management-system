# ADR 0004：本期不做定位增强和语音识别

状态：接受（2026-08-10）

本次编码明确排除：

- 浏览器/微信定位、地图 SDK、经纬度采集、逆地理编码、自动区县建议。
- 语音识别、ASR 厂商接口、转写文本、置信度和校对工作流。

当前区县只能人工下拉选择；语音仅为可选原始录音。代码库不预留伪造的定位/转写字段，避免形成未履行的合规告知或“看似可用”的空实现。

未来定位重新立项必须先明确地图供应商账号、终端覆盖、HTTPS 环境、用户主动授权、区县映射准确率和“不保存原始坐标”验收。未来 ASR 重新立项必须先明确供应商数据出境/留存边界、后端代理、转写可编辑确认、置信度保留、失败回退和费用预算。两项均应作为独立 PR，不与当前业务上线捆绑。
