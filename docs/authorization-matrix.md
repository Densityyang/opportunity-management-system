请求通过 `X-Role-Grant-Id` 明确当前授权。一名用户切换角色后，服务端只按新授权判断，不合并该账号的其他角色能力。

区县经理的“本区县管理”只包含下级角色：可以创建本区县一线上报人、个人侧管理员、组织侧管理员并调整这些本区授权；不能看到或配置区县经理、市公司、高级市公司管理员、系统管理员，也不能查看只属于其他区县的账号。停用本区县角色只影响该条授权，不会越权停用整个账号。

高级市公司管理员可以配置全区域的一线、区县经理、个人侧、组织侧和市公司角色，但不能查看或管理高级市公司管理员和系统管理员。系统管理员具有配置平面的全局权限，却默认没有商机正文和录音读取权限。

账号或授权停用后立即失去相应能力；当前分派被替换后旧承接人立即失去正文访问。系统会阻止停用仍有未办结任务的承接授权、存在未办结商机时的最后一名区县经理，以及最后一个有效系统管理员。
